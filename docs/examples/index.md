## Running Examples

1. Install the framework:
   ```bash
   pip install reactive-agents
   ```

2. Set up your LLM provider (e.g., Ollama):
   ```bash
   ollama pull llama3
   ```

3. Run an example:
   ```bash
   python examples/basic_agent.py
   ```
